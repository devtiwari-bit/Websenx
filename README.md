# Websenx

Official website of Websenx, an independent digital development brand by Dev Tiwari.

Live site: https://devtiwari-bit.github.io/Websenx/

## Files
- `index.html` the whole website (logos, project photos and legal pages are built in)
- `robots.txt`, `sitemap.xml` for search engines
- `site.webmanifest`, `sw.js` installable app support and offline fallback
- `favicon.*`, `apple-touch-icon.png`, `icon-*.png`, `logo.svg`, `og-image.png` branding and share preview

## Deploy
Upload every file to the repository root and enable GitHub Pages (Settings > Pages).
